# Project Documentation

## Project Title
PocketSmart AI – Your Smart Budget & Recommendation Assistant

## Project Overview

PocketSmart AI is a GenAI-powered recommendation system that provides budget-based suggestions for different planning needs.

## Main Use Cases

### Home Planner
Provides recommendations based on budget, room type and required quantities.

### Party Planner
Provides recommendations based on budget, guest count, event type and venue.

### Jewelry Planner
Provides recommendations based on budget, occasion and preferred style. An outfit image can also be provided.
