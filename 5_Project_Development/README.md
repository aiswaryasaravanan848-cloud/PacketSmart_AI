# Project Development

## Project Title
PocketSmart AI – Your Smart Budget & Recommendation Assistant

## Development Technologies

- FastAPI
- Python
- Gemini AI
- HTML
- CSS
- JavaScript
- Jinja2
- Render

## Developed Features

### User Authentication
- User registration
- User login
- Authentication
- Logout

### Home Planner
Users provide budget and home-related requirements to generate recommendations.

### Party Planner
Users provide budget, guest count, event type and venue details to generate party recommendations.

### Jewelry Planner
Users provide budget, occasion and style. An optional outfit image can also be provided for analysis.

### AI Recommendation
Gemini AI is used to generate budget-based recommendations.

### Recommendation History
Generated recommendations are stored and can be viewed later through the history and details pages.

## Deployment

The application was deployed using Render.
