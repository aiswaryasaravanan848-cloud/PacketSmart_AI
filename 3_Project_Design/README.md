# Project Design

## Project Title
PocketSmart AI – Your Smart Budget & Recommendation Assistant

## System Design

PocketSmart AI consists of:

- Frontend: HTML, CSS and JavaScript
- Backend: FastAPI
- AI Layer: Gemini AI
- Authentication: User login and authentication
- Database/Storage: Recommendation history and session data

## Main Modules

1. User Authentication
2. Home Planner
3. Party Planner
4. Jewelry Planner
5. Gemini AI Recommendation Engine
6. Recommendation History
7. Recommendation Details

## Application Flow

User Input → FastAPI Backend → Gemini AI → Recommendation Generation → Display Results → Save History

## User Interface

The application provides a responsive interface for entering budget and planning requirements and viewing AI-generated recommendations.
