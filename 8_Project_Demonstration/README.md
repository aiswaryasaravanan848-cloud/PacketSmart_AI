# Project Demonstration

## Project Title
PocketSmart AI – Your Smart Budget & Recommendation Assistant

## Project Demo

The project demonstrates an AI-powered budget recommendation system with three planners:

- Home Planner
- Party Planner
- Jewelry Planner

## Demo Flow

1. Open the PocketSmart AI application.
2. Login/Register as a user.
3. Select a planner.
4. Enter the required budget and details.
5. Generate AI-based recommendations.
6. View the recommendation results.
7. Check Recommendation History.
8. Open recommendation details.

## Project Purpose

The purpose of PocketSmart AI is to provide useful recommendations based on the user's budget and planning requirements.

## Benefits

- Budget-based recommendations
- AI-powered suggestions
- Multiple planning categories
- Recommendation history
- Easy-to-use interface
